正方形 K の回転体

A(0,0,0),\ B(1,0,0),\ C(1,1,0),\ D(0,1,0)
回転角 \theta = 360°
不透明度： 断面の高さ t = 0.00
※ 断面は回転し終えた（360°）立体のものです
K_x：y^2+z^2 \le 1,\ 0 \le x \le 1
K_y：x^2+z^2 \le 1,\ 0 \le y \le 1
V(K_x) = V(K_y) = \pi
V(K_x \cap K_y) = \int_{-1}^{1} (1-t^2)\,dt = \dfrac{4}{3}
V(K_x \cup K_y) = 2\pi - \dfrac{4}{3} \approx
