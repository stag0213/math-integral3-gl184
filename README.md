# 正方形 K の回転体 K_x・K_y 可視化アプリ

正方形 $K$ を $x$ 軸、$y$ 軸のまわりにそれぞれ 1 回転してできる立体 $K_x$、$K_y$ を 3D で可視化する Web アプリです。
HTML ファイル 1 つで動き、インストールやビルドは要りません。

## 問題設定

4 点

- $A(0,0,0)$
- $B(1,0,0)$
- $C(1,1,0)$
- $D(0,1,0)$

を頂点とする正方形の周と内部を $K$ とします。

- $K_x$：$K$ を $x$ 軸のまわりに 1 回転してできる立体
- $K_y$：$K$ を $y$ 軸のまわりに 1 回転してできる立体

## 主な機能

| 機能 | 内容 |
|------|------|
| 回転アニメーション | スライダーか再生ボタンで回転角 $\theta$ を 0°〜360° の範囲で変え、立体ができていく様子を表示します |
| 表示の切り替え | 正方形 $K$（緑）、$K_x$（赤）、$K_y$（青）、共通部分 $K_x \cap K_y$（黄）をそれぞれ表示・非表示にできます |
| 不透明度の調整 | $K_x$ と $K_y$ を半透明にして、内側の共通部分を見られます |
| 断面表示 | 平面 $z = t$ で切った断面を 3D 画面と 2D 図（上から見た図）に表示し、断面積の値も出します |
| 数式表示 | KaTeX を使い、根号・添字・積分記号などを正しい形で表示します |

## 使い方

1. `index.html` をブラウザで開きます。
2. インターネットに接続した状態で使ってください。ライブラリを CDN から読み込みます。

### 操作方法

| 操作 | 動作 |
|------|------|
| 左ドラッグ | 視点の回転 |
| 右ドラッグ | 視点の平行移動 |
| マウスホイール | 拡大・縮小 |
| 「▶ 回転アニメ」ボタン | 回転アニメーションの再生・停止 |
| 「0°に戻す」ボタン | 回転角を 0° に戻す |

> **補足：** 断面表示は回転し終えた（$\theta = 360^\circ$）立体のものです。

## 数学的な背景

### 各立体

$K_x$、$K_y$ はどちらも半径 1、高さ 1 の円柱です。

$$
K_x : y^2 + z^2 \le 1,\quad 0 \le x \le 1
$$

$$
K_y : x^2 + z^2 \le 1,\quad 0 \le y \le 1
$$

$$
V(K_x) = V(K_y) = \pi
$$

### 平面 $z = t$ による断面 $(-1 \le t \le 1)$

$w = \sqrt{1-t^2}$ とおくと、断面は次のようになります。

| 立体 | 断面 | 面積 |
|------|------|------|
| $K_x$ | $0 \le x \le 1,\ -w \le y \le w$ | $2\sqrt{1-t^2}$ |
| $K_y$ | $-w \le x \le w,\ 0 \le y \le 1$ | $2\sqrt{1-t^2}$ |
| $K_x \cap K_y$ | $0 \le x \le w,\ 0 \le y \le w$（正方形） | $1 - t^2$ |
| $K_x \cup K_y$ | — | $4\sqrt{1-t^2} - (1-t^2)$ |

### 体積

共通部分の体積：

$$
V(K_x \cap K_y) = \int_{-1}^{1} (1 - t^2)\,dt = \frac{4}{3}
$$

和集合の体積：

$$
V(K_x \cup K_y) = V(K_x) + V(K_y) - V(K_x \cap K_y) = 2\pi - \frac{4}{3} \approx 4.9499
$$

## トラブルシューティング

- **画面が真っ黒で何も表示されない**
  インターネットに接続しているか確認してください。ブラウザの開発者ツール（F12）のコンソールにエラーが出ていないかも確認してください。
- **ファイルを直接開くと動かない**
  ブラウザの設定によっては `file://` で開いたときに制限がかかることがあります。その場合は、ローカルサーバーを立ち上げて開いてください。

  ```bash
  # Python がある場合
  python -m http.server 8000
  # → ブラウザで http://localhost:8000 を開く
  ```
- **数式が LaTeX のコードのまま表示される**
  KaTeX を読み込めていません。ネットワーク接続を確認してください。数式以外の機能はそのまま使えます。
